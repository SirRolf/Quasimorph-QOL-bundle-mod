# Quasimorph QOL bundle

![thumbnail icon](media/thumbnail.png)

## Features
- Click on Magnum upgrade recources to go to the stock exchange
- Use Hotkey (Press E while hovering over item)
- Drop Hotkey (Press F while hovering over item)
- Disassemble Hotkey (Press X while hovering over item)
- Show travel time on station context menu even when there is no mission

## Planned Features
- Show total concentrations of mission
- Always see story contracts
